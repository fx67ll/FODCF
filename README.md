# FODCF
## 📖 项目简介
`FODCF` 基于 `Vue + Element` 构建，是面向个人场景的综合后台管理系统。
统一承载各类业务台账管理、服务器运维监控、数据可视化统计、系统参数配置、日常事务管理等能力。
整体采用组件化架构持续迭代，支持多角色权限视图隔离，不断优化交互体验、浏览器兼容性与数据安全规范。
与移动端 `FODCA` 应用数据互通，打造**「PC深度运维配置 + 移动端轻量化录入查询」**的闭环使用体验。

## ✨ 核心能力概览
- 📊 多维度业务台账管理、数据聚合统计、可视化图表、批量数据操作
- 🖥️ 服务器运维监控面板，支持服务启停管控、日志查阅、安全策略管理
- 📝 个人事务管理：收支台账、富文本备忘录、系统公告、通勤记录等工具模块
- 🀄 SaaS预约租户管理体系，包含用户权限控制、预约记录查询与可视化展示
- 🤖 AI业务后台：模型、赛季、规则、日志全链路配置管理能力
- 🔐 系统底层管控：菜单管理、密钥配置、登录鉴权、操作日志审计
- 🏠 差异化角色工作台首页，聚合动态统计卡片、高频快捷入口

## 🧱 技术架构特性
- 🧩 持续抽离公共业务组件，统一全局交互样式，降低代码耦合度
- 🛡️ 前后端协同推进安全体系升级，外部接口代理转发，敏感信息脱敏保护
- ⚡ 内置请求防抖、防重复提交、自适应布局，兼容PC、平板多类浏览器访问
- 🔄 与移动端 FODCA 共享后端服务，业务数据双向实时同步

## 📈 长期迭代方向
持续围绕四大方向稳步演进：
1. 🏠 工作台首页体验升级，完善多角色视图、动态排序、快捷操作面板
2. 🖥️ 运维监控模块能力拓展，丰富服务管控、安全日志可视化能力
3. 🛡️ 安全机制持续加固，细化权限隔离、敏感配置访问校验策略
4. 🎨 统一表单、查询弹窗、提示组件交互规范，标准化页面开发范式

## 🔗 生态联动
> **FODCA（移动端） ↔ FODCF（PC管理后台）**  
> 共享同一后端服务，业务数据双向实时同步。  
> `移动端满足碎片化随手操作 -->> PC端完成复杂配置、批量管理、深度数据分析。`

## ⚠️ 重要说明
1. **定位声明**：本项目为**个人私有工具平台**，面向自用开发，不面向公众商业化运营；功能高度贴合个人使用习惯，不适合通用场景。
2. **相关提示**：平台所有统计功能仅作为个人记录载体，**不构成任何参考建议**，请理性使用。
3. **访问限制**：游客模式仅可浏览示例数据，完整账号使用权限需要联系作者开通。
